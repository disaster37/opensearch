# Plan: Replace `Params map[string]string` with typed parameter structs

## Context

Multiple request structs in `api/options.go` use `Params map[string]string` for URL query parameters. This is error-prone for consumers who must know the exact string keys. Replacing with typed structs provides compile-time safety, IDE autocomplete, and self-documenting code.

**Current pattern (bad):**
```go
Params: map[string]string{"refresh": "true", "routing": "abc"}
```

**Target pattern (good):**
```go
Params: &IndexParams{Refresh: "true", Routing: "abc"}
```

## Typed Parameter Structs to Create

### 1. `IndexParams` (for IndexRequest)

OpenSearch params for `PUT/POST /{index}/_doc/{id}`:
- `refresh` (string) — "true", "false", "wait_for"
- `routing` (string)
- `timeout` (string) — e.g. "1m"
- `version` (int64)
- `version_type` (string) — "internal", "external", "external_gte", "force"
- `if_seq_no` (int64)
- `if_primary_term` (int64)
- `pipeline` (string)
- `require_alias` (bool)

```go
type IndexParams struct {
    Refresh       string
    Routing       string
    Timeout       string
    Version       int64
    VersionType   string
    IfSeqNo       int64
    IfPrimaryTerm int64
    Pipeline      string
    RequireAlias  bool
}

func (p *IndexParams) ToMap() map[string]string {
    if p == nil {
        return nil
    }
    m := make(map[string]string)
    if p.Refresh != "" { m["refresh"] = p.Refresh }
    if p.Routing != "" { m["routing"] = p.Routing }
    if p.Timeout != "" { m["timeout"] = p.Timeout }
    if p.Version != 0 { m["version"] = strconv.FormatInt(p.Version, 10) }
    if p.VersionType != "" { m["version_type"] = p.VersionType }
    if p.IfSeqNo != 0 { m["if_seq_no"] = strconv.FormatInt(p.IfSeqNo, 10) }
    if p.IfPrimaryTerm != 0 { m["if_primary_term"] = strconv.FormatInt(p.IfPrimaryTerm, 10) }
    if p.Pipeline != "" { m["pipeline"] = p.Pipeline }
    if p.RequireAlias { m["require_alias"] = "true" }
    if len(m) == 0 { return nil }
    return m
}
```

## Implementation Steps

### Step 1: Add typed param structs to `api/options.go`

For each of the 10 request types:
1. Create a `{RequestType}Params` struct with all available OpenSearch URL parameters as typed fields
2. Add a `ToMap() map[string]string` method that converts non-zero fields to the `map[string]string` format
3. Use `strconv` for numeric-to-string conversion
4. Return `nil` when no params are set (to avoid empty maps)
5. Replace `Params map[string]string` field in each request struct with `Params *{RequestType}Params` (pointer so nil is valid)

**Important:** The `ToMap()` method must be on a pointer receiver and handle `nil` gracefully:
```go
func (p *IndexParams) ToMap() map[string]string {
    if p == nil {
        return nil
    }
    // ...
}
```

### Step 2: Update service implementations

In `api/document_service.go` and `api/search_service.go`, replace:
```go
for k, v := range req.Params {
    r.SetQueryParam(k, v)
}
```
with:
```go
r.SetQueryParams(req.Params.ToMap())
```

Or keep the existing loop pattern since `ToMap()` returns `map[string]string`:
```go
for k, v := range req.Params.ToMap() {
    r.SetQueryParam(k, v)
}
```

### Step 3: Update `api.NewSearchRequest` adapter

In `api/options.go`, the `NewSearchRequest` function converts `querydsl.SearchRequest.URLParams()` to `api.SearchRequest.Params`. Update to use the typed struct:
```go
func NewSearchRequest(r *querydsl.SearchRequest) (*SearchRequest, error) {
    body, err := r.Body()
    if err != nil {
        return nil, fmt.Errorf("search request body: %w", err)
    }
    params := &SearchParams{}
    // Set params from querydsl URLParams if present
    urlParams := r.URLParams()
    if v, ok := urlParams["search_type"]; ok { params.SearchType = v }
    if v, ok := urlParams["routing"]; ok { params.Routing = v }
    // ... etc
    return &SearchRequest{
        Indices: r.Indices(),
        Body:    rawBody(body),
        Params:  params,
    }, nil
}
```

**Alternatively**, keep `api.SearchRequest.Params` as `*SearchParams` and have `NewSearchRequest` populate it from `querydsl` URL params. This is the cleanest approach.

## Backward Compatibility Consideration

This is a **breaking change** for consumers who currently pass `Params: map[string]string{...}`. Since this is a v4 module targeting OpenSearch 3.4+, and the goal is to improve the API, this breaking change is acceptable.

To minimize friction:
- The `Params` field changes from `map[string]string` to `*{Type}Params`
- Consumers must update their call sites
- Typed structs provide compile-time safety and IDE autocomplete

## Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Missing OpenSearch params | Start with the most commonly used params; additional params can be added later |
| Breaking change for consumers | Document in changelog; the improvement justifies the break |
| `ToMap()` conversion bugs | Unit tests for each `ToMap()` method covering zero-value and populated cases |
| `NewSearchRequest` adapter complexity | Keep it simple; only map params that `querydsl` already supports |
